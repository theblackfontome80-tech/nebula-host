Ajouter un site

  1. Sur GitHub, ouvre le dossier sites du dépôt et clique sur Add file → Upload files.
  2. Glisse le dossier de ton site (il doit contenir un index.html). Son nom devient l'adresse : /sites/mon-site/
  3. Clique sur Commit changes. Le site apparaît ici automatiquement en moins d'une minute.
